Most of the tools you need are provisioned automatically before your start date. This page tells you what to expect, what requires a manual request, and how to get unblocked quickly if something is missing.

## Auto-Provisioned Accounts

These accounts are created when HR adds your employee record and become active the moment you log in with your company email. You should have all of them on day one.

| Tool | Used for |
|------|----------|
| Company email | Primary communication |
| Slack | Team messaging |
| Project tracker | Task and sprint management |
| HR portal | Benefits, time off, and payroll |
| SSO agent | Single sign-on for all other apps |
| Password manager | Secure credential storage |

<Note>
  Log in to each of these tools on your first day to confirm access. It's much easier to catch a provisioning issue early than after you need the tool urgently.
</Note>

## Request-Based Access

Some systems require a separate request because they are role-specific or have limited licensed seats. Access is not granted automatically — you or your manager must initiate a request.

| Tool | How to request |
|------|----------------|
| Infrastructure | File an [IT access request](/it-security/access-requests) |
| Git repository | Ask your tech lead to invite you directly |
| Design platform | Ask the design lead |
| Analytics tools | Request via IT ticket — manager approval required |
| Customer data systems | Manager and security team approval required |

## Something Missing?

If an auto-provisioned account is missing or you need request-based access, file an [access request ticket](/it-security/access-requests).

<Tip>
  When filing an access request, include three things to avoid back-and-forth delays: the name of the tool you need, why you need it, and your manager's name for approval sign-off. Routine requests are fulfilled within one business day.
</Tip>
